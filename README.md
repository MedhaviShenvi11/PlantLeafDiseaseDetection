# 🌿 AgriVision AI – Plant Leaf Disease Detection

AgriVision AI is a web-based AI application that detects plant leaf diseases from uploaded images.

Users can upload a leaf image and receive an AI-based prediction with the predicted disease, crop, confidence score, symptoms, prevention methods, and recommended steps.
